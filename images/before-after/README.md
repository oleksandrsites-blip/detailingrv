# Фото «до / після»

Кожна категорія — окрема папка з двома фото одного й того самого авто з **однакового ракурсу й кадрування**:

```
polishing/   полірування
interior/    хімчистка салону
headlights/  відновлення фар
complex/     комплексний детейлінг
```

1. Покладіть у папку `before.jpg` і `after.jpg` (горизонтальні, бажано від 1600 px по довгій стороні).
2. Запустіть `python3 tools/optimize-images.py pairs` — вийдуть `before.webp`, `after.webp` і зменшені `-800.webp`.
3. Перезберіть сайт: `python3 build.py clients/detailingrv.json --out index.html`.

Зараз у папках лежать **тимчасові заглушки**, зроблені з одного фото. Замініть їх своїми парами перед публікацією.
